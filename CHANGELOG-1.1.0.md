# FPMCI 1.1.0

## 中文
- 项目更名为 **FPMCI — First-Person Mouse Control Integration**（第一人称鼠标操控整合）。
- 重做浅色航空简报风格界面，更新导航、字体、状态栏与按钮层级；修复数值输入框显示不完整。
- 常用设置加入 DLSS 帧生成开关，默认关闭；加入 13 项导弹比例引导数值编辑与提示，保存后下次启动生效。
- 增加游戏 Build 26002268 的版本识别与原生镜头适配，保留 Build 25201480 支持；本次 UI 更新不改变飞机飞控算法。
- 完整包保留外置资源结构，EXE 仅作启动与设置入口，便于后续修改。

**验证范围：** 已完成离线版本/签名检查、原生镜头与设置测试及界面检查；更新后的游戏内实测验收仍待完成。

## English
- Renamed to **FPMCI — First-Person Mouse Control Integration**.
- Redesigned the launcher with a light aviation briefing theme, refreshed navigation, typography and status display; fixed clipped numeric inputs.
- Added a DLSS Frame Generation switch (off by default) and a 13-value missile guidance editor with hints. Changes apply on the next launch.
- Added build identification and native camera compatibility for Build 26002268 while retaining Build 25201480 support. The UI update does not change flight-control calculations.
- Kept external resources alongside the launcher for easier maintenance.

**Validation:** Offline signatures, native camera/settings tests and UI checks passed. In-game acceptance testing on the updated game is still pending.
