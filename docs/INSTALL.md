# FPMCI 安装说明

1. 将完整安装包解压到游戏目录以外的位置，不要在 ZIP 内直接运行。
2. 双击文件夹中的 **AC8Workbench.exe**。
3. 在“安装与启动”中选择游戏位置、Steam 程序和安装方案，点击左下角“保存设置”。
4. 第一次使用或移动文件夹后，复制页面中的启动选项，粘贴到 **Steam → 游戏属性 → 通用 → 启动选项**。
5. 点击右下角“开始游戏”。默认勾选“从 Steam 启动”，由 Steam 先处理云同步，再启动 MOD 会话。

取消“从 Steam 启动”后，使用原 MOD 的直接会话启动流程；Steam 仍须已运行。首次安装建议保留默认勾选项。
游戏退出后，原有归属校验、备份及清理流程会自动执行。异常退出可在“模组管理”中清理和恢复。

## 选择安装内容

| 安装方案 | 内容 |
|---|---|
| 飞控 + 导弹模块 | 鼠标飞控、比例引导与按弹种选择的近炸增强 |
| 仅鼠标飞控 | 鼠标飞控，保留原版导弹 |

“导弹强化”页提供 13 项比例引导参数；11 类弹种可分别打开近炸并编辑触发距离、爆炸半径和范围伤害。近炸默认关闭，SASM 原版空爆保留。直击参考为战役基础伤害，与可编辑的范围伤害是不同参数。

更改安装方案前退出游戏，修改后下次启动应用。

## 更新与文件夹

EXE 是启动与设置入口。请保留旁边的 payload、runtime、配置与脚本；发布和复制时需要整个文件夹。
移动文件夹后重新保存安装设置，并替换 Steam 启动选项。不要同时使用多个安装包启动同一游戏。
本包沿用原 MOD 适配要求：Windows x64，游戏 Build 25201480 或 26002268。启动前会检查游戏版本和已有加载器的归属。

## 设置保存

EXE 中的设置在下次启动时应用。游戏内实际调整过的灵敏度、自由观察缩放、PEACE/WAR、机外相机模式及机头十字会自动保存到这个 MOD 文件夹。
工具保持打开时会自动读取这些变化；同一项目的游戏内调整优先，其他未保存的菜单调整保留。保存前会建立设置备份。

## 修改外置资源

INI 设置可直接修改。修改 payload 资源后运行 Update-Resources.cmd 更新校验；修改 C++ 则重编 DLL 后更新校验。
更改资源无需把 MOD 重新打包进 EXE。许可证、原作者署名与来源记录保留在 LICENSE、THIRD_PARTY_NOTICES.md 和 source 中。


1.1.0：请运行 AC8Workbench.exe（窗口名称 FPMCI）。新游戏版本已完成离线签名与模块检查，游戏内实测验收待完成。帧生成默认关闭，设置保存后下次启动生效。


## 附加 MOD（1.1.8 起）

「模组管理」顶部显示已添加的 MOD 和启停状态。点击「管理附加 MOD」，在独立窗口导入 ZIP 或解压后的目录，也可以把文件拖入窗口。支持含 `Scripts/main.lua` 或 `dlls/main.dll` 的 UE4SS MOD。先查看导入预览，已有同名项会跳过。导入后列表自动更新。可切换启停或移到 `ue4ss-mods-removed`。移除的原件可重新导入。

MOD 目录内部的 Pak／IoStore 文件随其部署。目录外的资源和压缩包附带的 UE4SS 加载器由预览提示，游戏资源请按相应 MOD 的安装说明处理。随包的 UEHelpers 对应本包的 UE4SS 版本。其他共享库及原生 DLL 的兼容性需按附加 MOD 的要求核对。

「常用设置 → 保存飞行记录」默认关闭。需要采集 FE／Shadow CSV 时，打开开关并保存，下次启动生效。
