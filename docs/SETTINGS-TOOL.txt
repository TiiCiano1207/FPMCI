AC8 飞控设置工具 1.0

打开：双击 MOD 文件夹中的 AC8Settings.exe。
如果工具未找到 MOD，点击左下方“切换文件夹”，选择包含 MouseAim-Settings.ini 的完整 MOD 文件夹。
可调整：鼠标灵敏度、默认 PEACE/WAR 模式、辅助强度、驾驶舱/机外相机、相机响应、准星颜色/透明度/显示、键位等。
滑块适合快速调整；右侧数值框可以精确输入。百分比、米、倍率等单位显示在标签中。
颜色可用选色器、预设，或直接输入 #RRGGBB。预览为示意，游戏光晕与背景会影响最终色感。
点击“保存设置”后，在下一次从这个 MOD 包启动游戏时生效。不会即时修改正在运行的游戏。

本页默认：仅重置当前分类，尚需点击保存。默认保留驾驶舱兼容模式与 #70FF90 绿色准星。
自动备份：每次保存前，在 MOD/settings-backups 中备份三份配置文件。
恢复最近备份：恢复上一次保存前的状态；恢复前的当前设置也会备份。
重新读取配置：用于外部编辑后刷新；保存会检测其他程序的修改，避免覆盖新配置。
键位：手动轴键应与游戏内绑定一致；MOD 的配置工具不会修改游戏本身的键位。

程序是 Windows x64 原生 WPF EXE，使用本机 .NET Framework；不需要 Python、Node 或打开 PowerShell 窗口。
配套 MOD 修改已接入 Hud-Style.ini。将 EXE 用于旧的未适配包时，颜色文件不能单独让旧版 MOD 支持可调颜色。
代码在 MOD/source/SettingsTool 中；在安装了 .NET Framework 编译器的 Windows 上运行 build.ps1 可重新编译。

验证：参数范围/整数/颜色/按键冲突、保存与精确恢复、外部修改检测、UI 数值与颜色保存、相机选择和本页默认通过。
界面已检查标准与小窗口尺寸。准星颜色加载/复制链路离线检查通过；没有启动游戏进行此次验收。
