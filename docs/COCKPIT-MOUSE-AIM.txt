驾驶舱鼠标飞控修正版 Fix1（本地候选，2026-10-12）

已修正
1. 按住 C 移动鼠标可在驾驶舱内转头；只改变相机旋转，保留驾驶舱位置和 FOV。
   松开 C 后由游戏恢复镜头，C 按下/释放的边界帧不改变飞行目标。
2. 正常鼠标操纵时，飞控实际目标限制在屏幕内并留出圆环边距。
   限制适配当前 FOV、窗口尺寸和相机旋转，也覆盖普通与独立输入两条路径。
   C 自由观察时保持原飞行目标；看向别处时，原目标仍可能不在视野中。

使用
关闭游戏后，从原 MOD 包重新启动。模式 2 已保持为启动默认值。
V 使用游戏原生视角切换进入驾驶舱；F1 应显示 STOCK / COCKPIT。
F3 循环：拉远跟随(1) → 原生相对机位(0) → 驾驶舱兼容(2) → 拉远跟随。
绿色准星保留。旧的机外两档不采用新增目标边界限制。

验证
DLL 编译和五项原生回归通过：相机上下文、过场恢复、原生 HUD 快照、参考准星、键盘接管。
新增断言覆盖：C 只改变旋转、松开恢复原生相机；极端鼠标移动的目标投影仍有边距；
C 按下/释放保留目标，即使自由观察镜头已经转向；两条输入路径均限制目标。
尚未实机验证自由观察、手感与不同飞机/任务中的表现。
